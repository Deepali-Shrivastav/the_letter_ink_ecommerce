# Brand Guidelines

## Official visual source

The attached brand set establishes the identity through:
- A calligraphic black/ink mark
- A soft pink watercolor field
- Warm blush background
- Editorial serif lettering
- Handwritten/script descriptor
- Fine botanical line-art
- Small muted decorative dots

These are treated as established brand elements.

## Logo usage

### Primary
Use the supplied full logo lockup for:
- Main website header when space permits
- About/brand introduction
- Footer brand area
- Marketing landing pages

### Compact
Use the supplied mark-led version when:
- Header space is limited
- Mobile navigation is collapsed
- Favicon/app icon variants are required and an approved crop is available

### With tagline
Use only where the descriptor adds useful context. Do not repeat the tagline on every page.

## Clear space

Keep at least the height of the lowercase `x`-height of the wordmark around the logo. In practical UI terms, use a minimum 16px internal breathing room and increase to 24–32px in prominent placements.

## Do not

- Stretch the logo
- Change its colors
- Add drop shadows
- Add gradients
- Outline or stroke the logo
- Place text directly over the mark
- Recreate the mark as an SVG from memory
- Crop important portions of the lockup

## Color character

The brand uses a warm blush base with rose accents and deep ink text. Website UI should use these colors in a restrained ratio:

**Ink > neutral surfaces > blush background > rose accent.**

Pink should not be used for every button, border and heading simultaneously.

## Typography character

The logo's wordmark is an editorial serif. The tagline is handwritten/script. The interface should respect that contrast:
- Serif for major editorial/display headings
- Neutral sans-serif for interface and body copy
- Script only as a rare brand accent, preferably via the supplied artwork rather than UI text
