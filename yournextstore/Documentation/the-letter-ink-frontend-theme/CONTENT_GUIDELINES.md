# Content Guidelines

The Letter Ink should sound personal, assured and crafted.

## Voice

- Warm
- Clear
- Confident
- Specific
- Human
- Never salesy for its own sake

## Avoid

- "Revolutionary"
- "Cutting-edge"
- "Next-generation"
- "Unlock your potential"
- Generic AI-style filler
- Unsubstantiated superlatives

## Prefer

Instead of:
> We create innovative solutions for all your creative needs.

Use:
> Hand-finished lettering and design created for invitations, brands and meaningful occasions.

## Headings

Keep headings short and editorial.

## CTAs

Prefer specific actions:
- View the work
- Enquire about a project
- See the services
- Start a project

Avoid vague:
- Learn more
- Get started
- Explore now
