## Button hierarchy

1. Primary — rose/ink action
2. Secondary — outlined
3. Tertiary — text link

Do not render multiple competing primary buttons in one compact region.

## Cards

Cards are used to group genuinely related content. They should not be used as a default wrapper for every section.

## Modals

Use only for focused tasks that must interrupt the current context. Prefer a page or disclosure when possible.

## Tabs

Use tabs only when the user is switching between related views at the same hierarchy level.

## Accordions

Use for secondary information, FAQs, or progressive disclosure. Do not hide critical information behind an accordion.
