# Contributing

## Workflow

1. Create a focused branch.
2. Make the smallest coherent change.
3. Reuse existing tokens/components.
4. Test desktop and mobile.
5. Run lint, typecheck and build.
6. Review accessibility and content.
7. Open a focused pull request.

## Naming

React components:
`PascalCase`

Files:
`kebab-case.tsx`

CSS custom properties:
`--color-*`, `--space-*`, `--radius-*`

## Pull requests

Include:
- What changed
- Why it changed
- Screenshots for visual work
- Accessibility considerations
- Responsive behavior
- Any new assets

Do not introduce a new library for a problem that the existing stack can solve simply.
