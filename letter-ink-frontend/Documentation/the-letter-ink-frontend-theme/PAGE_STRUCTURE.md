# Page Structure

Recommended information architecture for The Letter Ink.

```text
/
├── Home
├── About
├── Services
│   ├── Custom Lettering / Calligraphy
│   ├── Brand / Packaging
│   └── Event / Personal Stationery
├── Portfolio
├── Contact
└── Legal
    ├── Privacy
    └── Terms
```

Adapt these routes to the actual business scope. Do not publish placeholder pages merely to fill the navigation.

## Marketing page anatomy

```text
SiteHeader
Hero
Intro / value proposition
Selected work
Services
Process / trust
CTA
SiteFooter
```

## Content hierarchy

Each page should answer:
1. What is this?
2. Why does it matter?
3. What examples/proof exist?
4. What should the visitor do next?
